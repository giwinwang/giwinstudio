# Bundled fonts

GIWIN Studio bundles the following fonts for canvas and export rendering:

The application UI uses the native platform stack (`-apple-system`, `PingFang SC`, `Microsoft YaHei`) so desktop controls retain familiar system rendering. Bundled fonts remain the fixed fallback for generated deliverables and exports.

- `GIWIN-Sans-Regular.otf`: Noto Sans SC Regular
- `GIWIN-Sans-Medium.otf`: Noto Sans SC Medium
- `GIWIN-Sans-Bold.otf`: Noto Sans SC Bold
- `GIWIN-Serif-Bold.ttf`: Source Han Serif SC Heavy

Noto Sans SC and Source Han Serif are licensed under the SIL Open Font License 1.1. The complete license text is included in `OFL.txt`.

Rename notice: the local filenames use the `GIWIN Sans` / `GIWIN Serif` family labels required by the application CSS. The original font names and copyright notices remain in the font metadata.
