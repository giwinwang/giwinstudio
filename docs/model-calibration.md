# 新模型接入与校准

每个新增生图模型在进入用户模型列表前，必须完成同一套对比和适配，不能只验证接口能否返回图片。

## 固定测试素材

- 一组固定角度室内结构图。
- 一组多机位结构图。
- 一张无参考图结果。
- 一张暖色材质参考图。
- 一张冷蓝光影参考图。
- 一张包含明确吊顶、灯槽和地面铺贴方向的参考图。

## 必测模式

1. 无参考图，使用默认方案。
2. 仅氛围参考。
3. 材质+光影参考。
4. 单张重绘。
5. 同组一致性继续生成。

## 验收维度

| 维度 | 检查内容 |
| --- | --- |
| 物理结构 | 墙、门窗、梁柱、吊顶造型、灯槽、家具位置和相机角度 |
| 材质迁移 | 沙发、墙面、柜体、地面、地毯的材质和颜色 |
| 光影迁移 | 冷暖、曝光、环境色、阴影、高光与反射 |
| 参考污染 | 是否新增参考图中的吊顶格栅、线条灯、拼花或家具造型 |
| 图像缺陷 | 水印、乱码、重复纹理、结构融合和透视错误 |
| 运行指标 | 耗时、失败率、输出尺寸和费用 |

物理结构错误属于阻断级问题，不能通过提高外观相似度抵消。

## 注册模型档位

通过测试后在 `model-tuning.js` 中登记：

- 默认参考方式；
- 支持的参考方式；
- 仅氛围与材质+光影的颜色迁移强度；
- 物理结构保护等级；
- 模型偏向和已知限制。

新增模型默认先使用安全通用档位，只有通过固定素材对比后才能获得专用档位。

## 参考方式联动

| 环节 | 仅氛围 | 材质+光影 |
| --- | --- | --- |
| 节点参数 | 保存 `referenceMode=atmosphere` | 保存 `referenceMode=material` |
| 物理结构 | 始终锁定 | 始终锁定 |
| 提示词 | 只迁移光影、色彩和氛围 | 同时迁移材质、表面与光影 |
| 颜色预处理 | 使用模型档位中的低强度 | 使用模型档位中的高强度 |
| 项目材质 | 保留机位图/材质节点材质 | 无材质节点时由参考图接管 |
| 参考模式应用范围 | 首次生成、重绘、继续生成 | 首次生成、重绘、继续生成 |

天气不跟随参考方式切换，始终作为独立的窗外天气与空气氛围控制。
