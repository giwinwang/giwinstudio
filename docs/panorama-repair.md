# 全景修复运行链路

## 目标

在不把大型 AI 运行时和模型放入主安装包的前提下，为 2:1 等距柱状全景提供接缝与上下极点修复。

## 处理流程

1. 校验源图为标准 2:1 ERP 全景。
2. 水平循环位移 50%，把原始边界接缝移到画布中线。
3. 在客户端进行接缝低频色差校正，保留原始高频纹理。
4. 将顶部和底部极点分别投影成 70° 切平面视图，尺寸为 768 或 1024。
5. 两张方图横向拼成 2:1 请求图，并以 12° 球冠生成圆形遮罩。
6. 仅上传约 `1536×768` 或 `2048×1024` 的拼图及遮罩到用户配置的修复模型。
7. 将返回结果重新拆成上下两张方图，按球冠权重回投到完整全景。
8. 恢复原来的 50% 水平位移，结果作为新图片节点写入画布。

上传过程不包含完整 4K/8K 全景。源图分辨率、Alpha 和非修复区域像素在客户端合成时保留。

## 修复后端

- `阿里云百炼 · 万相 2.1`：国内按图计费的首选在线后端。使用
  `wanx2.1-imageedit` 的 `description_edit_with_mask` 能力，只上传约 2K
  的极点半球拼图和黑白遮罩；默认 `0.14 元/张`，适合作为正式在线通道。
- `阿里云百炼 · 图像擦除补全`：不带提示词的纯遮罩补全模型，官方提供 500
  次免费体验。客户端额外生成前景保留遮罩，用于对比万相与专用补全模型的效果。
- `Replicate LaMa`：全景极点首选。客户端发送约 2K 极点拼图和遮罩，由 Replicate 的 LaMa 局部修复 API 返回结果。
- `GPT Image 2 / NanoBanana / Seedream`：配置后可作为备用局部修复模型。
- `RunningHub 工作流`：仅在配置了可接收极点拼图和遮罩的工作流时使用。

Replicate Token 在“设置 → 引擎 → Replicate（LaMa 局部修复）”中配置，并使用与应用内其他引擎相同的本机安全存储。Replicate LaMa 不会出现在普通文生图或图生图模型列表中。

## 代码边界

- `panorama-runtime.js`：独立球面投影、圆形遮罩、拼图和回投实现。
- `canvas.js`：调用现有模型配置、显示进度、取消任务和保存结果节点。
- `providers.js`：复用现有局部重绘路由。

该链路不依赖 FreeCCStudio，也不随产品分发 LaMa 权重或 Python 运行时。
