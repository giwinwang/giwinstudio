# GIWIN Studio 品牌标志

## 正式标志

- 用户于 2026-10-22 确认 `GIWINSTUDIO.png` 为 GIWIN Studio 的正式 Logo，不再使用此前评审阶段的其他候选方案。
- 标志由连续的深色 G 形块面组成，外轮廓接近正方形。
- 网页与界面中的标准透明矢量资源为 `icon-mark.svg`。
- Windows 窗口任务栏图标资源为 `icon.png`。
- Windows 桌面快捷方式使用多尺寸 `icon.ico`，不得指向 Electron 默认图标。
- 原始确认文件保留为 `GIWINSTUDIO.png`。

## 使用规则

- 开屏、登录页、主窗口顶栏和“关于”页必须引用同一版标志。
- 开屏与顶栏跟随当前主题：浅色主题显示深色标志，深色主题显示浅色标志。
- 开屏使用约 3 秒的主题色进度条，不再显示“画布引擎已就绪 · Konva”启动提示。
- 开屏品牌组合按原尺寸的 80% 展示；启动音效使用 `splash-start.wav` 并在开屏时播放一次，可在“设置 → 界面 → 启动音效”关闭或点“试听”。

## Copilot 入口

- “粒子魔方”是画布右下角入口及弹出对话界面的统一正式名称。
- 画布右下角使用“粒子魔方”作为 Copilot 入口，不再显示普通图标按钮。
- 入口点击区域为 `92px`；未打开项目时仍可悬停互动，但点击只提示先新建或打开项目，不打开 Copilot。
- 常态为缓慢漂浮的近球粒子云；鼠标悬停后聚合成同尺寸粒子魔方。
- 聚合状态下，鼠标在入口范围内移动直接控制朝向，横向可完成最高约 720° 的连续旋转。
- 点击聚合后的魔方打开 Copilot 对话；触屏首击聚合、再次点击打开对话。
- 入口需跟随深浅主题，并在系统启用减少动态效果时加快或省略过渡。
- 顶栏标志直接显示，不再套浅色圆角图标底块，避免小尺寸下被裁切或误读为按钮。
- 其他需要底托的界面使用浅纸色，保证标志清晰；不得直接使用低对比度深色块。
- 不得拉伸、旋转、改色或重新分解标志。
- 新页面和新增品牌入口应复用 `icon-mark.svg`，不得临时绘制另一版近似图形。
