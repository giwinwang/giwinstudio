# 极物 GIWIN Studio · v0.4.28（Beta）

当前版本：0.4.28 Beta。本文后续的运行说明和 M1 功能清单保留自早期版本，不能完整代表当前内测版的功能；请以应用内界面和当前源码为准。

## GIWIN Copilot（第一阶段）

- 右下角圆形入口或 `Ctrl+J` 打开右侧对话面板。
- 画布选中的图片会自动加入对话上下文，单次最多保留 24 张。
- 粒子魔方会把附件区中的真实图片按显示顺序发送给视觉模型，而不是只发送文件名；图片在后台按并发 2、最长边 640px、质量 0.84 准备，避免阻塞画布操作。
- 支持“只聊不改”“规划并确认”“自动规划执行”三种权限。
- 第一阶段支持多机位一致性渲染：识别4K要求、按每组最多4机位拆分批次、创建生成节点并运行群组。
- 已接入通用工作流调度：按节点连线拓扑顺序运行，失败只阻断下游分支，并可在人工节点处暂停。
- 支持从对话规划软装提取、高清放大、客户方案排版，以及直接运行画布中已选中的节点群组。
- 软装提取完成后会停在人工确认关卡；标记、局部重绘等节点不会被自动越过。
- 执行前可先放到画布检查，也可确认后直接运行；运行中可停止并保留已完成结果。
- 对话记录按项目保存在本机；执行计划会固定图片顺序与结果版本。

## 运行方法

1. 已装 Node.js 的话跳过；没装：nodejs.org 或镜像下载 LTS 版安装
2. 解压到纯英文无空格路径（如 G:\GIWINDESIGN）
3. 双击 启动.bat（首次自动装依赖；以后秒开）

## M1 更新说明

**本次新增（画布模块）：**
- 拖图入画布：从资源管理器把 SU 截图拖进来，落在指针位置
- Ctrl+V 粘贴：微信里复制图片 → 画布直接粘贴
- 右键菜单：导入 / 粘贴 / 新建便签 / 适应视图
- 缩放平移：滚轮缩放（5%–300%）、空格+拖拽或右键拖拽平移
- 双击图片 = 灯箱看大图；双击空白 = 适应视图
- 灵动岛：选中图头顶浮出 ⚡生成 / HD放大 / Q排版 / ☆定稿
- Q 对比排版：选中 ≥2 张图，一键等宽对齐成排
- 便签：钉在画布上的文字备忘，双击编辑
- 左侧"画布图片"列表：点击定位到图，★ 标记定稿
- 全套快捷键：按 ? 查看；Ctrl+Z/Y 撤销重做、Ctrl+D 复制、Ctrl+A 全选、F 聚焦、Delete 删除
- 自动存档：所有改动 0.8 秒内写入项目 Config/canvas.json，状态栏显示保存时间
- 图片存项目 Content/ 文件夹（数据与代码分离）

**M0 反馈批量修复：**
- 窗口菜单栏已隐藏（Alt 可唤出）
- 窗口/任务栏图标统一为极物标
- 登录页邮箱记忆（本机账号下拉 + 自动填上次邮箱）
- 设置 → 关于 → 查看许可协议（EULA 可重阅）

## 更新方法

解压覆盖软件文件夹即可（项目数据在 %APPDATA%\giwin-studio 和项目文件夹，不受影响）。
注意：M1 新增依赖 konva，覆盖后首次启动会自动补装（约一分钟）。
