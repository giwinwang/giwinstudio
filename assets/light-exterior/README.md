# Light exterior preset images

Place licensed or user-owned exterior photographs in this directory using these filenames:

- `city-dusk.jpg`
- `mountain-mist.jpg`
- `ocean-noon.jpg`
- `courtyard.jpg`
- `snow-peak.jpg`
- `rain-night.jpg`

Recommended crop: landscape 4:3 or 16:9, at least 640 x 360, no text or watermark.
