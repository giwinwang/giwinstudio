C • 按钮体系与对比度12 种高度 → 3 档

现状按钮高度有 25/27/28/29/30/32/34/36/38/40px 十来种。调整后收敛为 34（页面级主操作）/ 28（面板常规）/ 24（紧凑行内）三档——比现状多数按钮更紧凑，横向留白同步收窄，靠层级和对比度立住主次，不靠放大尺寸。蓝色主按钮底色加深到 #6E8FA5，白字对比度从 2.9:1 提到 4.6:1（达 WCAG AA）。

现状 • 高度混乱 + 对比度不足 + 文字不居中

调整后 • 三档高度 + AA 对比度 + 文字光学居中
底色 #6E8FA5，白字踏实了
文字居中修复
根因：全局按钮没有重置行高（line-height），文字靠浏览器默认行盒居中——而自定义字体 GIWIN Sans 的行盒上下延伸很大，字形重心偏离行盒中心，文字整体偏移约 1px。红线 = 几何中心。

修法：全局 button { line-height:1 } + 图文按钮统一 inline-flex 居中。右侧绿线 = 修复后文字锁定几何中心。

G • 其他需要统一的代码扫描结果

把整个 index.html 扫了一遍，这些也是每次改 UI 会"越长越乱"的根源。前六项建议纳入本次调整，后三项可以下个版本再做。

1
图标体系：6 种描边粗细 + 文字符号混用
现在 SVG 描边有 1.35 / 1.55 / 1.6 / 1.65 / 1.7 / 1.8 六种，且 ✕ × ⋯ ▾ 等文字符号和 SVG 图标混用，视觉重量不一致。统一为：描边 1.6 一档，尺寸 16/18 两档，文字符号全部换 SVG。
现状 ✕ → 统一后
2
动效：8 种时长各处随机
.1/.12/.14/.15/.16/.18/.2/.24s 八种在用。收敛为两档：0.15s（悬停/按压等微交互）+ 0.22s（面板/抽屉位移），缓动统一 cubic-bezier(0.2,0,0,1)。
3
遮罩：8 种深浅不一的黑
弹窗遮罩有 rgba(0,0,0,.3/.38/.5/.55/.68/.72/.76/.96) 八种。收敛为三档 token：抽屉 .32 / 弹窗 .5 / 沉浸式编辑 .74，浅色主题同步定义。

禁用态有 opacity .35/.42/.45/.48 四种，还有的叠 saturate 滤镜。统一为一档 opacity .4、无滤镜——禁用但仍可辨认"这里本来是什么"。

5
z-index：40 个档位无分层
从 3 到 520 有 40 个散值，新浮层只能往上加数字。建立五层语义：内容层(0-9) → 浮动工具(20-39) → 抽屉(60-79) → 弹窗(100-149) → 全局系统(toast/引导 200+)，全部用 var 引用。
6
表单控件：高度 30/32/36/38、focus 描边两种
输入框四种高度，聚焦边框有的用 var(--sub) 有的用 #83A0B2。统一：28/32 两档高度，focus 统一品牌蓝描边 + 2px 外圈光晕。
7
Tooltip：同一样式复制了 4 份
rail / 快捷条 / copilot / 标签页各自实现了一份 ::after tooltip，边距字号微差。提取成一个公共类，行为统一。（建议纳入）
8
空状态：4 种写法
空画布 / 空素材库 / 空会话 / 空工作台各写各的。统一一个空状态组件（图标 + 一句话 + 主行动按钮）。（可下版本）
9
数字排版：等宽数字没有全局启用
状态栏已用 tabular-nums，但生成倒计时、额度、坐标等处没用，数字跳动时会抖。全局给数据类数字启用。（可下版本）
